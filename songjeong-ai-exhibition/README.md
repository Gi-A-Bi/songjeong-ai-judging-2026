# 송정 AI 작품마을

서울송정초 2026 AI 공모전의 감상용 2D 웹 전시관 초안입니다.

## 실행

이 폴더의 index.html을 브라우저에서 엽니다. 설치나 빌드가 필요 없습니다.
방향키 또는 화면 버튼으로 광장을 이동하고, 입구나 상단 메뉴로 세 전시관에 들어갑니다.
전시관에서 예시 작품을 열어 다음 작품을 보거나 글짓기 쪽을 넘길 수 있습니다.

## 파일

- index.html — 화면 구조와 기본 디자인
- app.js — 광장 이동, 전시관 전환, 작품 감상
- works.js — 분야별 예시 3편과 데이터 형식
- HANDOFF.md — 클로드 인수인계 문서
