# 송정 AI 작품마을

서울송정초 2026 AI 공모전의 감상용 2D 웹 전시관입니다. 심사 시스템과 분리된 독립 정적 페이지로, 설치나 빌드 없이 동작합니다.

## 실행

이 폴더의 index.html을 브라우저에서 엽니다. 정적 호스팅(학교 홈페이지, GitHub Pages 등)에 폴더째 올려도 됩니다.

- 중앙 광장: 방향키 또는 화면 버튼으로 걸어가 전시관 입구에 닿으면 들어갑니다. 입구나 상단 메뉴를 눌러 바로 들어갈 수도 있습니다.
- 전시관: 구역별 목록, 구역 바로가기, 제목 찾기를 제공합니다. 주소의 #character, #poster, #writing으로 전시관을 바로 열 수 있습니다.
- 작품 보기: 카드를 누르면 크게 봅니다. 캐릭터·포스터는 ＋/－ 버튼이나 이미지 탭으로 확대하고, 확대 상태에서 끌어서 봅니다. 글짓기는 쪽 넘기기 버튼, 좌우 방향키, 손가락으로 밀기(확대 전)로 넘깁니다. 마지막 쪽에서 오른쪽으로 넘기면 다음 작품으로 이어집니다.

## 파일

- index.html — 화면 구조
- style.css — 광장·전시관·뷰어 디자인
- app.js — 광장 이동, 전시관 전환, 구역·찾기, 작품 감상
- works.js — 작품 데이터와 형식 설명 (현재는 예시)
- images/samples/ — 감상 기능 확인용 예시 이미지 (실제 작품으로 교체)
- HANDOFF.md — 클로드 인수인계 문서

## 실제 작품으로 바꾸기

1. 학교에서 공개 범위를 정한 전시용 사본을 받습니다.
2. 이미지를 images/ 아래에 넣습니다. 글짓기는 학년·반·이름을 가린 사본을 쪽마다 한 장씩 준비합니다.
3. works.js의 예시 항목을 실제 작품으로 교체합니다. 형식은 works.js 상단 주석을 따릅니다. id는 고유해야 하고, 이미지마다 alt(대체 텍스트)를 넣습니다.
4. 점수, 심사위원 정보, 심사 시스템 주소, 계정 키는 어디에도 넣지 않습니다.
5. 배포 전에 디벗과 휴대폰에서 광장 → 전시관 → 작품 확대 → 다음 작품/다음 쪽 → 광장 복귀를 확인하고, 관람 대상과 공개 범위를 담당자와 확정합니다.
